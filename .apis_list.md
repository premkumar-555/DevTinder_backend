# All APIs List

## authRouter /auth
- POST /signup
- POST /login
- POST /logout

## profileRouter /profile
- GET /profile/view
- PATCH /profile/edit

## connectionRequestRouter 
- POST /request/send/:status/:toUserId - status : [interested, ignore]
- POST /request/review/:status/:requestId - status : [accepted, rejected]

## userRouter
- GET /user/requests/received
- GET /user/connections
- GET /user/feed?page=1&limit=10 - get users data to show in feed of user
