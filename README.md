## Introduction 
This project is part of Namaste NodeJs backend development course taught by Akshay Saini on NamasteDev.com platform.
It is an application, where developers can create account, connect and chat with each other in real time.
This project gives me a detailed knowledge about building user interface, backend integrated with socket.io to handle reat time chats, notifications, user online/offline info displaying, reusable components etc. Please explore this app and can provide suggestions. 
   
 ##  Tech-stack used
  
   ```
   Frontend : HTML, CSS, Javascript, ES6+, React JS, Redux-toolkit, Cookies, Tailwind CSS, Daisy UI, Socket.IO
   
   Backend   : Node JS, Express JS, MongoDB, Mongoose, Socket.IO, Node-Cron, JsonWebToken, Bull MQ (Message Queueing), AWS - EC2, SES, NgInx etc
   ```

 ## Features

 | Serial No            | Feature                                                            |
| ----------------- | ------------------------------------------------------------------ |
| 1 | User singup and login by JWT Authentication & Bcrypt |
| 2 | Home/Feed Page with user profiles, where user can connect or reject user profiles |
| 3 | Real time notifications on receiving or accepting connection requests by Socket.IO |
| 4 | Real time one-on-one chat and chat notifications by Socket.IO |
| 5 | Real time email notifications on new connection requests by AWS SES Mailing Service |
| 6 | Real time daily email notifications on pending connection requests by AWS SES Mailing Service , Cron Job (Node-cron) & Message Queueing (Bull MQ) |
| 7 | Real time user online/offline info display at all required pages using Socket.IO & In-memory Cacheing  |
| 8 | User password encryption/decryption using Bcrypt |
| 9 | User profile update feature |
| 10 | User logout feature |

By working on this project I have revised all core and advanced concepts of NodeJs which is a javascript run time environment outside the browser.
Implementing features like real time chat, real time app and email notifications, user online/offline info displaying using tools like Socket.IO, AWS SES given me indept knowledge on their usages.
I have deployed the frontend and backend apps on AWS EC2 instance using NgInx for htttp servers, ubuntu as linux based operating system, PM2 as Nodejs server's 24/7 process manager etc.
As part of a small break and upskilling myself to make a career transition from an intermediate full stack developer to a Backend developer have worked on this project.
